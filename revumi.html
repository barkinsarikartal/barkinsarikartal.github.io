Revumi

A multiplayer party game where players answer questions, predict each other’s choices, and reveal results in sync. Built with real-time rooms and reconnection handling.

Web ↗ App Store ↗ Google Play ↗

1 / 7 · Feature graphic

My role

I planned the product and directed AI-assisted visual design and implementation through store release. I reviewed generated code, debugged issues, and checked changes with unit tests and CI. I configured Cloudflare and Railway and managed deployment workflows.

Keeping players in sync

A disconnected phone should be able to return to the room without losing its place. The FastAPI backend manages room state and sends updates over WebSockets. Reconnection handling restores the player’s state, while scheduled reveals keep results synchronized across phones.

Testing and deployment

Backend unit tests cover game behavior, with frontend tests and type checks supporting changes to the interface. GitHub Actions runs automated checks. The Vue frontend is hosted on Cloudflare and the FastAPI backend and PostgreSQL database run on Railway.
