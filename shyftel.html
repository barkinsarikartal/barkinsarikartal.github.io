Shyftel

A survival game for web and mobile with daily seeded runs and leaderboards. The server replays submitted runs to verify scores.

Web ↗ App Store ↗ Google Play ↗

1 / 8 · Feature graphic

My role

I planned the game and directed AI-assisted coding and artwork creation through mobile store releases. I reviewed implementation decisions and generated code, investigated failures, and maintained automated tests and CI checks. I configured the Cloudflare and Railway infrastructure and managed deployments.

Verifying a run on the server

A leaderboard needs more than a score reported by the client. Shyftel records player inputs and upgrade choices so the server can replay a run using the matching simulation version. Separating the deterministic simulation from Three.js lets the same logic run without a browser.

Testing and deployment

Automated checks cover simulation boundaries, determinism, and server-side validation. GitHub Actions runs checks before release. Cloudflare hosts the web application; Railway hosts the Hono API and PostgreSQL database. Capacitor packages the game for iOS and Android.
