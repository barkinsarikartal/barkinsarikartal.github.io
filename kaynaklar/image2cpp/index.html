Görselini küçük ekrana taşı

Bir logo veya fotoğrafı image2cpp ile ekranında gösterebileceğin veriye dönüştür. Ekranına uygun yolu seç, örneği indir ve kendi görselinle değiştir.

1. Önce ekranını kontrol et

Bu örnekler iki belirli kurulum içindir. Farklı ekran sürücüsü, çözünürlük veya kart kullanıyorsan pinleri ve kütüphaneyi uyarlaman gerekir.

Arduino IDE Kütüphane Yöneticisi’nden Adafruit GFX Library ve ekranına göre Adafruit SH110X veya Adafruit ILI9341 kur. Önerilen bağımlılıkları da yükle. Nano için Arduino AVR Boards, ESP32 için Espressif’in esp32 kart paketi gerekli.

image2cpp.com’u aç ↗. OLED için sade, yüksek kontrastlı bir logo; TFT için renkli bir görsel seç. Aşağıdaki adımlar özellikle bu sitenin çıktı biçimine göre hazırlanmıştır.

2A. Nano + SH1106 OLED

  1. UPLOAD ile görselini yükle.
  2. OUTPUT TYPE → PAPER DISPLAY (B/W 1-bit). İsmi “paper” olsa da OLED için gereken tek renkli çıktı budur.
  3. DISPLAY PRESET → SSD1306 / SH1106 128×64.
  4. Görsel kartındaki VAR NAME alanını image yap. W = 128, H = 64, FORMAT = MONO 1-bit olduğunu kontrol et.
  5. THRESHOLD ile ayrıntıları ayarla; gerektiğinde Invert seç. Önizlemedeki beyaz pikseller OLED’de yanar.
  6. Görsel kartındaki COPY düğmesiyle diziyi ve genişlik/yükseklik tanımlarını birlikte kopyala.

Üst ayarları mevcut görsellere uygulamak için “Update all images (global override)” seçeneğini kullan veya görsel kartındaki değerleri doğrudan değiştir.

VCCModülün belgelerinde belirtilen besleme

Klasik Nano’nun mantık seviyesi 5 V’tur. OLED modülünün I²C girişleriyle uyumluluğunu kontrol et; yalnızca 3.3 V mantık destekliyorsa uygun seviye dönüştürücü kullan. Besleme gerilimi desteği ile sinyal gerilimi desteği aynı şey değildir.

Bu site tek renkli veriyi dikey 8 piksellik gruplarla üretir. Aşağıdaki kod bunu okuyarak SH1106’ya çizer; standart drawBitmap() çağrısına doğrudan vermek görüntüyü bozabilir.

OLED Arduino kodunu göster
#include <Arduino.h>
#include <Wire.h>
#include <Adafruit_GFX.h>
#include <Adafruit_SH110X.h>
#include "images.h"

// Classic Arduino Nano (ATmega328P): SDA = A4, SCL = A5.
constexpr uint8_t OLED_ADDRESS = 0x3C;
Adafruit_SH1106G display(128, 64, &Wire, -1);

static_assert(sizeof(image) == image_width * ((image_height + 7) / 8),
              "Image size does not match vertical-page MONO format");
static_assert(image_width <= 128 && image_height <= 64, "Image too large");

void setup() {
  Serial.begin(115200);
  Wire.begin();
  Wire.beginTransmission(OLED_ADDRESS);
  if (Wire.endTransmission() != 0) {
    Serial.println(F("OLED not found at 0x3C. Check wiring/address."));
    while (true) delay(1000);
  }
  if (!display.begin(OLED_ADDRESS, true)) {
    Serial.println(F("SH1106 initialization failed."));
    while (true) delay(1000);
  }
  display.clearDisplay();
  const int x0 = (128 - image_width) / 2;
  const int y0 = (64 - image_height) / 2;
  // image2cpp.com MONO: page-major, one byte = 8 vertical pixels, LSB at top.
  for (int y = 0; y < image_height; ++y) {
    for (int x = 0; x < image_width; ++x) {
      uint8_t value = pgm_read_byte(&image[(y / 8) * image_width + x]);
      if (value & (1u << (y % 8))) {
        display.drawPixel(x0 + x, y0 + y, SH110X_WHITE);
      }
    }
  }
  display.display();
  Serial.println(F("Image displayed."));
}

void loop() { delay(100); }

2B. ESP32 + dikey ILI9341 TFT

  1. Renkli görselini yükle.
  2. OUTPUT TYPE → RGB DISPLAY (RGB565).
  3. DISPLAY PRESET → ILI9341 240×320.
  4. VAR NAME → image. W = 240, H = 320, FORMAT = RGB565 olduğunu kontrol et.
  5. Görsel kartındaki COPY ile kodun tamamını kopyala.

Görsel oranı korunarak alana sığdırılır; boşlukları azaltmak için dikey, 3:4 oranında bir görsel kullanabilirsin.

VCC ve LED / BLModülün besleme ve arka ışık bağlantı talimatına göre

Bu kod SPI modülü içindir; paralel bağlantılı Uno shield için değildir. MISO, dokunmatik ve SD kart kullanılmıyor. ESP32 GPIO’ları 3.3 V seviyesindedir. Arka ışığı besleme gereksinimini kontrol etmeden doğrudan GPIO’ya bağlama.

Örnekte tft.setRotation(2) ile dikey görünüm kullanılıyor. Ters görünürse 0 yap; ikisi de 240×320 dikeydir.

TFT Arduino kodunu göster
#include <Arduino.h>
#include <SPI.h>
#include <Adafruit_GFX.h>
#include <Adafruit_ILI9341.h>
#include "images.h"

// Classic ESP32 DevKit + SPI ILI9341 (not a parallel Uno shield).
constexpr int TFT_SCK = 18;
constexpr int TFT_MOSI = 23;
constexpr int TFT_CS = 27;
constexpr int TFT_DC = 26;
constexpr int TFT_RST = 25;
Adafruit_ILI9341 tft(&SPI, TFT_DC, TFT_CS, TFT_RST);

static_assert(sizeof(image) / sizeof(image[0]) == image_width * image_height,
              "Image size does not match RGB565 format");
static_assert(sizeof(image[0]) == 2, "Use uint16_t RGB565 output");
static_assert(image_width <= 240 && image_height <= 320, "Image too large");

void setup() {
  Serial.begin(115200);
  SPI.begin(TFT_SCK, -1, TFT_MOSI, TFT_CS);
  tft.begin(10000000);
  tft.setRotation(2); // Portrait: 240 x 320
  tft.fillScreen(ILI9341_BLACK);
  tft.drawRGBBitmap((tft.width() - image_width) / 2,
                    (tft.height() - image_height) / 2,
                    image, image_width, image_height);
  Serial.println("Image sent to TFT.");
}

void loop() { delay(100); }

3. Kendi görselini yerleştir ve yükle

  1. ZIP’i aç. Klasör adıyla aynı isimdeki .ino dosyasını Arduino IDE’de aç; yanındaki images.h aynı klasörde kalmalı.
  2. İstersen önce değiştirmeden yükle: OLED örneğinde dama deseni, TFT örneğinde kırmızı, yeşil, mavi ve beyaz şeritler bulunur.
  3. images.h sekmesinin tüm içeriğini, siteden kopyaladığın kodla değiştir. Yalnızca sayıları değil, dizi ve boyut tanımlarını da yapıştır.
  4. İsimler image, image_width ve image_height olmalı. OLED dizisi const unsigned char, TFT dizisi const uint16_t olmalı; PROGMEM ifadesini koru.
  5. Kartını ve portunu seçip yükle. Seri monitör hızı 115200.

TFT’de 240×320 RGB565 görsel 153.600 bayt tutar. Bu nedenle TFT örneği Nano için değil ESP32 içindir. OLED’de 128×64 tek renkli görsel 1.024 bayttır; Nano örneğinde görsel flash bellekte tutulur.

Bir şey ters giderse

OLED bulunamadı
SDA/SCL, ortak GND ve beslemeyi kontrol et. 0x3C varsayımı yanlış olabilir; I²C taramasıyla adresi doğrula. SSD1306 ekran kullanıyorsan SH1106 sürücüsünü seçme.
OLED’de görüntü parçalı veya anlamsız
MONO 1-bit çıktısını kullandığından emin ol. Bu örnek image2cpp.com’un dikey sayfa düzeni içindir.
Beyaz/siyah ters
Sitedeki Invert seçeneğini değiştirip çıktıyı yeniden al.
TFT siyah veya tamamen beyaz
Besleme, arka ışık, CS/DC/RST ve SPI kablolarını kontrol et. Seri monitörde “Image sent” yazması fiziksel ekranın çalıştığını doğrulamaz.
Image too large / size does not match
Doğru çözünürlük ve formatla yeniden dönüştür. Diziyi eksiksiz kopyala.
image was not declared
Sitede VAR NAME alanını image yap ve çıktıyı tekrar kopyala.
Nano’ya yükleme başarısız
Doğru port ve işlemci seçimini kontrol et. Bazı eski Nano kartlarında ATmega328P (Old Bootloader) gerekir.
