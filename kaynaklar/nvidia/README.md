# NVIDIA rehberi

Paylaşım yolu: /kaynaklar/nvidia/

Promptlar ve rehber metni index.html içinde. Python örneği ilk-istek.py içinde;
örneği değiştirirken sayfadaki api-code alanını da güncelle.
Ana portfolyo menüsüne eklenmedi. Ortak kaynak tema dosyalarını kullanır.
Canlı API isteği çalıştırılmadı; API anahtarı veya hesap kullanılmadı.
