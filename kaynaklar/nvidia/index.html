1. Hesabını hazırla

  1. NVIDIA Build’i aç ve hesap oluştur ya da giriş yap.
  2. İstenirse e-posta doğrulamasını ve organizasyon bilgilerini tamamla. Kendi proje bilgilerini kullan.
  3. Telefon doğrulaması istenirse tamamla; API anahtarı oluştururken gerekebilir. Ekranlar hesap ve bölgeye göre farklılaşabilir.
  4. Bir modelin Playground bölümünü aç ve aşağıdaki metin promptlarından biriyle başla. Görsel promptu için görsel giriş destekleyen bir model seç.

Buluttaki denemeler için NVIDIA ekran kartına ihtiyacın yok. Ücretsiz erişim öğrenme ve prototip geliştirme içindir; sınırsız kullanım veya ücretsiz üretim altyapısı garantisi değildir. Gizli proje verilerini ve kişisel bilgileri deneme girdilerine ekleme.

2. Hangi modelle başlayayım?

Bunlar başlangıç seçenekleri; bir performans sıralaması değil. Kartta Playground veya API erişimini kontrol et.

  • Meta Llama 3.3 70B Instruct ↗

    Özetleme, fikir geliştirme, JSON çıkarma ve basit kod sorularını bununla dene.

  • NVIDIA Nemotron modelleri ↗

    Katalogda bir metin / reasoning modelini seçip aynı kod veya planlama sorusuna verdiği cevabı karşılaştır. Model kimliğini karttan al.

  • Meta Llama 3.2 90B Vision Instruct ↗

    Görsel yükleyip içeriği hakkında soru sormak için. Arayüz görsel yüklemeyi sunmuyorsa kartın görsel API örneğini kullan veya katalogdaki erişilebilir başka bir vision modeli seç.

4. Cevapları nasıl karşılaştırırsın?

Aynı girdiyi iki modele, yeni sohbetlerde ver. Ayarlar sunuluyorsa temperature ve çıktı sınırını aynı tut. Tek bir denemeden genel bir “en iyi model” sonucu çıkarma.

  • Doğruluk: Özet 12 Ekim ile 8 Ekim’i karıştırıyor mu? Mekân uyduruyor mu?
  • Talimat takibi: İstenen madde sayısını ve JSON biçimini koruyor mu?
  • Kod: Boş liste için None, [0, 2] için 1, [2, 4, 6] için 4 üretiyor mu? Kodu ayrıca çalıştır.
  • Belirsizlik: Görmediği veya bilmediği bilgileri açıkça belirtiyor mu?
  • Hız: Bekleme süresini not et; bulut yoğunluğu da süreyi etkiler.

5. Python ile ilk API isteği

Model sayfasından bir API anahtarı oluştur. Aşağıdaki dosyayı indirip terminalde python3 ilk-istek.py çalıştır. Ek paket gerekmez; anahtarı gizli girişte sorar. İstersen NVIDIA_API_KEY ortam değişkenini kullanabilirsin.

Bu örnek metin isteği gönderir; görseller için modelin kendi örneğini kullan. Anahtarı web sayfasına, GitHub’a veya videoya koyma. Model erişimi değişirse karttaki kimliği NVIDIA_MODEL ortam değişkenine yaz.

Python dosyasını indir ↓

401: anahtar · 403: erişim / doğrulama · 404: model / adres · 429: istek sınırı. Örnek canlı API anahtarıyla çalıştırılmadı.
